Edge cases about ConfigFile.

Structure errors:

Directive errors:
# Directive with no value
→ "listen;" → only one word after split → ERROR
# Unknown directive
→ "banana 1234;" → not a known keyword → WARNING or ERROR
# Directive outside any block
→ "listen 8080;" appears before any "server {" → ERROR

Value errors:
# Port is not a number
→ "listen abc;" → can't convert to int → ERROR
# Port out of range
→ "listen 99999;" → not a valid port → ERROR
# Empty path for location
→ "location {" → no path between keyword and { → ERROR
# No servers found after parsing
→ file was valid but empty → ERROR

## ALL edge cases.

1/ Opening a server inside a server [ERROR valide].
2/ Opening a location outside a server
3/ File ends but a block is still open
4/ Unknown block type



Tokenization algo

into tokens like:
IDENT/ like {"location", "server", .....}
